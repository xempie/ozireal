## The console prototype

A working admin console with **sample data only** — no database, no auth, no server
actions, no AI calls. It exists so the shape of the product can be argued about before
the schema is committed to.

```bash
pnpm install
pnpm dev          # http://localhost:3000 -> /login
pnpm build        # production build, type-checks under strict TS
pnpm typecheck
```

**Sign in with** `sam@ozirealty.com.au` / `ozi2026`. The form checks a hardcoded pair in
the browser; there is no session to steal. Phase 1 replaces it with Auth.js.

Everything on screen comes from [`src/lib/sample-data.ts`](src/lib/sample-data.ts) and
[`src/lib/sample-data-2.ts`](src/lib/sample-data-2.ts). Controls that would mutate state
are inert.

### Charts

[`src/components/charts.tsx`](src/components/charts.tsx) wraps Recharts. Series colours
are `--c1..--c8` in `globals.css`, assigned in fixed slot order and never cycled, with
separate steps for light and dark that SVG resolves per theme. The light palette was
checked for colourblind separation before use; three of its hues sit below 3:1 against
the page, so every mark carries a visible label rather than relying on colour alone.

### Screenshots

`docs/screenshots/` holds every route in both themes, regenerated by:

```bash
pnpm build && pnpm start -p 3130 &
node scripts/screenshots.mjs 3130
```

That script also fails the run if any page logs a console error, which is the only
automated check the prototype currently has.

## Toolchain notes

- **Use `pnpm`, not `npm`.** The `npm` on this machine is broken — its shim resolves
  into a Herd-managed nvm directory whose `@npmcli/config` is missing, so any `npm`
  command exits with `MODULE_NOT_FOUND`. `pnpm` works. (`pnpm view` also fails, because
  it shells out to npm internally; `pnpm install`, `add`, `store prune` are all fine.)
- **Watch disk space.** `pnpm store prune` reclaims orphaned packages safely.
- The owner report's figures are generated by `docs/report/figures.py` and assembled by
  `docs/report/build_report.py`. They need `python-docx` and `matplotlib`; the
  throwaway virtualenv used to build them was deleted to reclaim space, so recreate one
  before regenerating.

## Regenerating the owner report

```bash
python -m venv .venv && .venv/Scripts/python -m pip install python-docx matplotlib
.venv/Scripts/python docs/report/figures.py
.venv/Scripts/python docs/report/build_report.py
```
